# 🐍 Snake Game using Python

A classic Snake Game developed using Python and pygame. The project demonstrates programming logic, collision detection, score tracking, and real-time game mechanics.

---

## ✨ Features

- 🎮 Real-time snake movement
- 🍎 Random food spawning
- 💥 Collision detection
- 📈 Score tracking
- ⌨️ Keyboard controls
- 🔄 Restart option after game over

---

## 🧰 Technologies Used

- Python
- pygame

---

## 🎯 Project Motivation

This project was created to strengthen my understanding of game development concepts, programming logic, and event-driven systems using Python.
